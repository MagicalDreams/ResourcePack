# Blockbench projects

Keep editable `.bbmodel` files, source textures, and model-specific notes in a named subfolder here. This folder is outside the resource-pack roots and is excluded from both pack builds.

- [Spotlight beam](spotlight-beam/README.md): shared tintable item-display beam, exported into both Generic RP and Parks RP under `assets/spotlight`. Runtime RGB tint requires Java 1.21.4+.

For shared models, update both pack exports together. Do not copy project sources or standalone reference pack ZIPs into the pack roots.
